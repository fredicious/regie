# Régie

Régie is a local lead-agent orchestrator: one lead agent plans and delegates to worker agents, with a web board to watch and steer. Design: `docs/superpowers/specs/2026-11-19-lead-agent-orchestrator-design.md`.

## Layout

- `crates/regie-core`: domain types and logic. It does no I/O (no files, network, processes, clock); callers pass everything in.
- `crates/regie`: library plus thin binary. Server, storage, agent adapters, CLI.
- Prompts live in `crates/regie/prompts/` (added with the first prompt).
- The web page lives in `web/` (Vite, Preact). TypeScript types are generated by ts-rs into `web/src/api/gen` (`TS_RS_EXPORT_DIR`).
- `src/regie`, `tests`, `pyproject.toml` are the older Python project; leave them alone.

## Commands

- `make test`: `cargo test`, `pnpm -C web test`, `pnpm -C web typecheck`
- `make web`: `pnpm -C web install --frozen-lockfile && pnpm -C web build` (writes `web/dist`)
- `make build`: `make web`, then `cargo build --release`. The release binary embeds `web/dist`; run `./target/release/regie serve`.
- `make dev`: prints the dev loop (below)

## Dev loop

Two terminals: `cargo run -p regie -- serve --no-open` (API on 127.0.0.1:7317; debug builds read `web/dist` from disk, so no rebuild after `make web`) and `pnpm -C web dev` (Vite with hot reload, proxying the API). Without `web/dist` the server serves a "run `make web`" note and the server tests that need the page skip.
